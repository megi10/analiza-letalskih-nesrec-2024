# airbus-vs-boeing-rom-2024
### Airbus vs. Boeing
Ta repozitorij vsebuje projekt, v katerem analiziram razlike med letalskima podetjema Airbus in Boeing. Ta projekt je pripravljen v sklopu predmeta **Računalniška orodja v matematiki 2023/24** v 1. letniku mojega študija na Fakulteti za matematiko in fiziko, Univerza v Ljubljani.

Za projekt pri predmetu uporabljamo računalniški program Mathematica.
